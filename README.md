# richardwojc.github.io
a website

## Planned Core Applications
- **Finder**: Mock file explorer with folder navigation.
- **Safari**: Mock web browser with address bar and static content.
- **Notes**: Simple text area for note-taking.
- **Calculator**: Functional calculator for basic arithmetic.
- **System Settings**: Mock settings panel with toggles and sliders.

## Full Experience Enhancements
- **Login Screen**: A macOS-style login interface to start the session.
- **Desktop Icons**: Interactive icons on the desktop for system elements.
- **Launchpad**: A full-screen app grid overlay for quick access.
- **Enhanced Finder**: Dynamic folder navigation in the sidebar.
- **Enhanced Safari**: Interactive address bar and window title updates.
